HTML

HTML stands for HyperText Markup Language and is the standard markup language for creating web pages.

It provides a structure for the content on a web page using tags such as <html>, <head>, <body>, etc.

<p>This is a paragraph</p>
  • HTML tags define the structure of the content
  • HTML attributes provide additional information about elements
CSS

CSS stands for Cascading Style Sheets and is used to style the appearance of web pages.

It allows you to change the colors, fonts, layout, and other visual aspects of the web page.

body {
background-color: #f1f1f1;
}
  • CSS selectors target specific elements to apply styles
  • CSS properties control the visual presentation
JavaScript

JavaScript is a high-level programming language that adds interactivity to web pages.

It can dynamically modify content, handle events, and interact with the user.

function greet() {
console.log("Hello, World!");
}
  • JavaScript variables store data
  • JavaScript functions perform actions
Python

Python is a versatile programming language known for its simplicity and readability.

It is used for web development, data analysis, artificial intelligence, and more.

print("Hello, World!")
  • Python has a clear and expressive syntax
  • Python supports object-oriented programming
Ruby

Ruby is a dynamic, object-oriented programming language with a focus on simplicity and productivity.

It has an elegant syntax and is often used for web development and scripting.

puts "Hello, World!"
  • Ruby is designed to be easy to read and write
  • Ruby has a strong community and rich ecosystem
